BookStore Admin Management System

Complete Spring Boot Application with JWT Authentication & Role-Based Access Control

Spring Boot 3.5.5 JWT Authentication MySQL Database Role-Based Security

Project Overview

This is a comprehensive admin management system for a bookstore built with Spring Boot. The system includes admin activity logging, daily sales analytics, and a complete role-based authentication system with JWT tokens.

Key Achievement: Implemented a full-stack admin system with 3 major modules: Activity Logging, Sales Analytics, and Role-Based Authentication with 30+ API endpoints and granular permission system.

Security Implementation

JWT Token Structure:

{ "sub": "admin-uuid-12345", // Subject (Admin User ID) "username": "admin.user", // Admin username "email": "admin@bookstore.com", // Admin email "userType": "ADMIN", // User type (always ADMIN) "adminRole": "SUPER_ADMIN", // Admin role hierarchy "department": "IT", // Admin department "employeeId": "EMP001", // Employee ID "fullName": "John Admin", // Full name "permissions": [ // Granular permissions array "USER_READ", "USER_WRITE", "USER_DELETE", "BOOK_READ", "BOOK_WRITE", "BOOK_DELETE", "ORDER_READ", "ORDER_WRITE", "ORDER_DELETE", "ADMIN_READ", "ADMIN_WRITE", "ADMIN_DELETE", "SYSTEM_CONFIG", "AUDIT_READ" ], "roles": ["ROLE_ADMIN", "ROLE_USER"], // Spring Security roles "iat": 1694123456, // Issued at timestamp "exp": 1694209856, // Expiration (24h) "jti": "admin-token-uuid" // JWT ID for tracking }

Role Hierarchy:

Role Description Access Level Key Permissions
SUPER_ADMINSuper AdministratorFull system accessAll permissions
ADMINAdministratorDepartment admin accessUser, Book, Order management
MANAGERManagerTeam management accessAnalytics, Reports
MODERATORModeratorContent moderation accessRead-only access
SUPPORTSupportCustomer support accessLimited read access

Complete API Endpoints

Authentication Endpoints:

POST /api/auth/login
Admin login with JWT token generation
POST /api/auth/register
Admin user registration
POST /api/auth/logout
Admin logout
GET /api/auth/profile
Get current admin profile

Admin Activity Logs (ADMIN+ roles):

GET /api/admin/activity/logs/recent
Get recent activities (last 24 hours)
GET /api/admin/activity/stats
Get activity statistics
POST /api/admin/activity/log
Create new activity log (SUPER_ADMIN only)

Analytics (MANAGER+ roles):

GET /api/analytics/daily-sales/recent
Get recent daily sales summaries
GET /api/analytics/dashboard?startDate=2025-09-01&endDate=2025-09-10
Get comprehensive analytics dashboard
POST /api/analytics/daily-sales/process
Process daily sales summary

Health Check:

GET /actuator/health
Application health status

Demo Instructions

Step 1: Database Setup

1. Run admin_role_system_setup.sql in MySQL Workbench 2. This creates all tables and sample data 3. Verify 3 admin users are created with different roles

Step 2: Start Application

cd Backend-o/Bookstore2 mvn spring-boot:run Application starts on http://localhost:8080

Step 3: Test Authentication

POST http://localhost:8080/api/auth/login { "username": "super.admin", "password": "password123" } Response: JWT token + admin user details

Step 4: Test Protected Endpoints

# Use JWT token in Authorization header Authorization: Bearer <your-jwt-token> GET /api/admin/activity/logs/recent GET /api/analytics/dashboard?startDate=2025-09-01&endDate=2025-09-10 GET /api/auth/profile
