Admin Activity Logs API

Track and monitor all administrative activities in the BookStore system.

GET
http://localhost:8080/api/admin/activity/logs/recent
Shows all admin activities from the last 24 hours
GET
http://localhost:8080/api/admin/activity/logs/admin/admin12345
Retrieves all activities performed by a specific admin user
GET
http://localhost:8080/api/admin/activity/logs/action/LOGIN
Filters activities by action type (LOGIN, LOGOUT, CREATE, UPDATE, DELETE)
GET
http://localhost:8080/api/admin/activity/logs/status/SUCCESS
Filters activities by status (SUCCESS, FAILED, ERROR)
GET
http://localhost:8080/api/admin/activity/logs/errors
Shows all activities that resulted in errors - critical for debugging
GET
http://localhost:8080/api/admin/activity/logs/date-range?startDate=2025-09-01T00:00:00&endDate=2025-09-16T23:59:59
Retrieves activities within a specific date range for reporting
GET
http://localhost:8080/api/admin/activity/stats/top-admins
Returns statistics showing which admins are most active
GET
http://localhost:8080/api/admin/activity/stats/common-actions
Shows statistics of the most frequently performed actions
POST
http://localhost:8080/api/admin/activity/log
Creates a new activity log entry with essential fields
{ "adminId": "admin12345", "adminUsername": "sayan", "actionType": "LOGIN", "status": "SUCCESS" }

Daily Sales Summary API

Comprehensive business analytics and sales reporting system.

GET
http://localhost:8080/api/analytics/daily-sales/recent
Shows the 10 most recent daily sales summaries
GET
http://localhost:8080/api/analytics/daily-sales/2025-09-15
Retrieves sales summary for a specific date
GET
http://localhost:8080/api/analytics/daily-sales/date-range?startDate=2025-09-01&endDate=2025-09-16
Gets sales summaries within a date range for trend analysis
GET
http://localhost:8080/api/analytics/stats/total-revenue?startDate=2025-09-01&endDate=2025-09-16
Calculates total revenue for a specific period
GET
http://localhost:8080/api/analytics/stats/total-orders?startDate=2025-09-01&endDate=2025-09-16
Counts total orders placed in a specific period
GET
http://localhost:8080/api/analytics/stats/total-items-sold?startDate=2025-09-01&endDate=2025-09-16
Counts total items sold in a specific period
GET
http://localhost:8080/api/analytics/stats/average-order-value?startDate=2025-09-01&endDate=2025-09-16
Calculates average order value for a specific period
GET
http://localhost:8080/api/analytics/stats/top-selling-items?startDate=2025-09-01&endDate=2025-09-16
Shows the best-selling items in a specific period
GET
http://localhost:8080/api/analytics/stats/least-selling-items?startDate=2025-09-01&endDate=2025-09-16
Shows the least-selling items in a specific period
GET
http://localhost:8080/api/analytics/dashboard?startDate=2025-09-01&endDate=2025-09-16
Returns a comprehensive dashboard with all key metrics
POST
http://localhost:8080/api/analytics/daily-sales/process
Creates or updates a daily sales summary entry
