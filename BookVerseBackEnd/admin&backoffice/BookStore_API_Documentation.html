Project Overview

This Spring Boot application provides comprehensive admin activity logging and analytics services for a bookstore management system. It includes RESTful APIs for tracking admin actions, monitoring system performance, and generating daily sales analytics.

Admin Activity Logging

Track all admin actions, login attempts, system changes, and errors with detailed metadata and timestamps.

Sales Analytics

Generate daily sales summaries, track revenue, identify top/least selling items, and monitor business performance.

Advanced Filtering

Filter logs by admin, action type, date range, status, and entity type for comprehensive analysis.

Performance Monitoring

Monitor slow operations, track error rates, and analyze system performance metrics.

Architecture

Admin Activity Logs API

Base URL: http://localhost:8080/api/admin

POST /api/admin/activity/log
Create a new admin activity log entry
GET /api/admin/activity/logs/recent
Get recent activities (last 24 hours)
GET /api/admin/activity/logs/admin/{adminId}
Get all activities for a specific admin
GET /api/admin/activity/logs/admin/{adminId}/page
Get paginated activities for a specific admin
GET /api/admin/activity/logs/action/{action}
Get activities by action type (LOGIN, LOGOUT, CREATE, etc.)
GET /api/admin/activity/logs/entity/{entityType}
Get activities by entity type (USER, BOOK, ORDER)
GET /api/admin/activity/logs/status/{status}
Get activities by status (SUCCESS, FAILED, ERROR)
GET /api/admin/activity/logs/date-range?startDate={startDate}&endDate={endDate}
Get activities within a date range
GET /api/admin/activity/logs/errors
Get all activities with errors
GET /api/admin/activity/logs/slow-operations?minDurationMs={duration}
Get operations slower than specified duration
GET /api/admin/activity/stats/top-admins
Get most active admins (last 7 days)
GET /api/admin/activity/stats/common-actions
Get most common actions (last 7 days)
GET /api/admin/activity/stats
Get comprehensive activity statistics

Analytics API

GET /api/analytics/daily-sales/recent

GET /api/analytics/daily-sales/{salesDate}

GET /api/analytics/daily-sales/date-range?startDate={startDate}&endDate={endDate}

GET /api/analytics/stats/total-revenue?startDate={startDate}&endDate={endDate}

GET /api/analytics/stats/total-orders?startDate={startDate}&endDate={endDate}

Usage Examples

Creating an Admin Activity Log

POST http://localhost:8080/api/admin/activity/log Content-Type: application/json { "adminId": "admin001", "adminName": "John Admin", "action": "LOGIN", "entityType": "USER", "entityId": "user123", "description": "User logged in successfully", "ipAddress": "192.168.1.100", "userAgent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36", "status": "SUCCESS", "sessionId": "sess_abc123", "durationMs": 150 }

Creating a Daily Sales Summary

POST http://localhost:8080/api/analytics/daily-sales/process Content-Type: application/json { "salesDate": "2025-09-10", "totalRevenue": 1500.50, "totalOrders": 25, "totalItemsSold": 45, "averageOrderValue": 60.02, "topSellingItem": "The Great Gatsby", "topSellingItemQuantity": 15, "leastSellingItem": "Advanced Mathematics", "leastSellingItemQuantity": 2 }

Getting Analytics Dashboard

GET http://localhost:8080/api/analytics/dashboard?startDate=2025-09-01&endDate=2025-09-10

Database Schema

admin_activity_logs Table

CREATE TABLE admin_activity_logs ( id BIGINT AUTO_INCREMENT PRIMARY KEY, admin_id VARCHAR(255) NOT NULL, admin_name VARCHAR(255) NOT NULL, action VARCHAR(255) NOT NULL, entity_type VARCHAR(255), entity_id VARCHAR(255), description TEXT, ip_address VARCHAR(255), user_agent TEXT, status VARCHAR(255) NOT NULL, error_message TEXT, metadata TEXT, session_id VARCHAR(255), duration_ms BIGINT, created_at DATETIME NOT NULL, INDEX idx_admin_id (admin_id), INDEX idx_action (action), INDEX idx_status (status), INDEX idx_created_at (created_at) );

daily_sales_summary Table

CREATE TABLE daily_sales_summary ( id BIGINT AUTO_INCREMENT PRIMARY KEY, sales_date DATE NOT NULL UNIQUE, total_revenue DECIMAL(10,2), total_orders INT, total_items_sold INT, average_order_value DECIMAL(10,2), top_selling_item VARCHAR(255), top_selling_item_quantity INT, least_selling_item VARCHAR(255), least_selling_item_quantity INT, created_at DATETIME NOT NULL, updated_at DATETIME, INDEX idx_sales_date (sales_date) );

Getting Started

  1. Start the Application: Run mvn spring-boot:run from the project directory
  2. Database Setup: Ensure MySQL is running on localhost:3306 with database 'bookstore_db'
  3. Test Health: Visit http://localhost:8080/actuator/health
  4. Create Sample Data: Use the POST endpoints to create activity logs and sales summaries
  5. View Analytics: Use the dashboard endpoint to see comprehensive analytics
